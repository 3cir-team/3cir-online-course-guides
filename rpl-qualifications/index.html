An overview of 3CIR's RPL qualification groups

Recognition of prior learning is always assessed against a specific, nationally recognised qualification. 3CIR keeps a public page that groups the kinds of qualifications it commonly discusses, so a reader can see the landscape before a detailed conversation.

That page is the qualifications 3CIR assesses through RPL. It covers qualification levels from Certificate II to Graduate Diploma and fields such as leadership and management, work health and safety, project management, security and risk, government investigations and business.

Treat this guide as a pointer to the live overview. It does not add a new qualification list, and it does not describe 3CIR as a college that issues awards. The overview page is the place for the current public grouping.
